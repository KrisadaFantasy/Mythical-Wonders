# Mythical Wonders
[Unciv](https://github.com/yairm210/Unciv) mod that add mythical places to Unciv as natural wonders. This mod provides tile graphic for both **HexaRealm** and **FantasyHex** tileset.

## ![Atlantis](https://github.com/KrisadaFantasy/Unciv-Mythical-Wonders/blob/main/Images/TileSets/HexaRealm/Tiles/Atlantis.png) Atlantis
- +2🎵, +2🪙, +2🔬
- Grants 100🎵 to any civilization that discover it.

## ![Mount Olympus](https://github.com/KrisadaFantasy/Unciv-Mythical-Wonders/blob/main/Images/TileSets/HexaRealm/Tiles/Mount%20Olympus.png) Mount Olympus
- +5🕊️, +5🎵

## ![Yggdrasil](https://github.com/KrisadaFantasy/Unciv-Mythical-Wonders/blob/main/Images/TileSets/HexaRealm/Tiles/Yggdrasil.png) Yggdrasil
- +3🕊️, +3🎵, +3😀
- Grants **Sentry** (+1 Sight) to adjacent Military Land units for the rest of the game.
